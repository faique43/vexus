vexus

Tells Claude Code where to look in your repo before it starts grepping.

21 seconds, with sound. The hint lines are real vexus 0.5.0 output on Express.

Try it on your repo

curl -fsSL https://raw.githubusercontent.com/faique43/vexus/main/install.sh | VEXUS_INIT=claude-code sh

Run it inside your repo on macOS or Linux. It installs the binary, adds a prompt hook to .claude/settings.json, and indexes in the background. Windows and other setups are in the install guide.

What it does

A hook runs on each prompt, finds the likely code locally with a semantic and call-graph index, and adds a few locations to what the agent sees, about 100 tokens. No tools to learn and no tool definitions billed every session. Indexing and search run on your machine and spend no agent tokens.
